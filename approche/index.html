Prendre contact

Méthode · sources · droits

La confiance se construit avant la publication.

Vestiges veut préparer les dossiers avec les personnes concernées, citer ses sources et leur laisser décider de ce qui peut être publié.

Voir les garantiesComprendre les statuts

Important

La méthode est encore en préparation. Ces principes décrivent le cadre visé ; ils ne signifient pas qu’un service complet est déjà en place.

01 — Comprendre d’abord

Trois garanties simples.

01

Avec la personne

Un dossier ne devrait pas être construit à distance de celle ou celui dont il raconte la pratique.

02

Jamais automatique

Un formulaire, un entretien ou un média partagé ne devient pas une publication par défaut.

03

Vous gardez la main

Vous devez pouvoir relire et corriger le dossier, choisir ce qui reste visible et demander le retrait d’un élément.

Ce qui est partagé n’est pas automatiquement public.

02 — Comment cela pourrait se passer

De l’échange à une publication éventuelle.

Dire pourquoi on demande une information

Avant de demander une information, Vestiges explique pourquoi elle est utile et ce que l’échange déclenche.

Demander seulement ce qui est utile

Le premier contact reste bref. Les photos, les sources détaillées et les droits sont abordés plus tard, si le projet avance.

Séparer les faits et les points de vue

Le dossier précise ce qui a été observé, ce qu’une personne rapporte, ce qu’une source confirme et ce qui relève de l’interprétation de Vestiges.

Relecture

La personne concernée relit les textes et choisit les images et informations qui peuvent être montrées.

Choisir ce qui sera publié

Avant de publier un texte, une image ou une information, Vestiges demandera un accord clair sur chacun de ces éléments.

Après la publication

Vous pourrez contacter une personne chez Vestiges pour demander une correction ou le retrait d’un élément.

03 — Ne pas tout appeler « vérité »

Distinguer ce qui est vérifié, rapporté ou interprété.

VérifiéSource consultée

L’information a été comparée à une source que l’on peut consulter.

DéclaréPropos attribué

Une personne ou un document le rapporte ; Vestiges ne l’a pas vérifié indépendamment.

InterprétationPoint de vue expliqué

Une lecture est présentée comme un point de vue, pas comme un fait.

À vérifierInformation incertaine

Ce qui manque ou reste incertain est indiqué comme tel.

04 — Visibilité

Chaque information peut rester privée ou être publiée selon votre choix.

Vous pouvez choisir séparément ce qui est visible pour une personne, une œuvre ou une image.

Visible par tousPartagé avec un groupeRéservé à l’équipe VestigesNon publié

Autoriser un texte ne signifie pas autoriser toutes les images, l’adresse exacte ou les informations privées. Chaque élément fait l’objet d’un choix séparé.

05 — Ce qui n’est jamais automatique

Un premier contact reste un premier contact.

01

Créer un profil ou une page publique.

02

Réutiliser un récit ou un média dans un autre contexte.

03

Ajouter une personne à une newsletter.

04

Transformer une information privée en relation publique.

05

Utiliser les informations partagées pour entraîner une intelligence artificielle.
